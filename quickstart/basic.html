⚡ OpenClaw 常用指令速查

更新日期：2026-04-07 | 适用版本：OpenClaw-zh v2026.4.2

💡 使用提示

以下指令基于 Windows 系统，在 CMD 或 PowerShell 中执行。点击"复制"按钮可直接复制到剪贴板。

🚀 启动与停止

openclaw start

启动 OpenClaw 网关服务

openclaw stop

停止网关服务

openclaw gateway restart

重启网关（常用配置更改后）

📦 插件管理

openclaw plugins list

查看已安装插件列表

openclaw plugins install <插件名>

安装新插件

openclaw plugins uninstall <插件名>

卸载插件

openclaw plugins update

更新所有插件

🔧 系统维护

openclaw update

检查并更新 OpenClaw 核心

openclaw upgrade

执行 OpenClaw 升级（推荐定期执行）

openclaw doctor

系统健康检查，诊断常见问题

openclaw logs tail

查看实时日志流

👥 员工管理（多机器人架构）

openclaw agent list

列出所有已配置的机器人员工

openclaw agent --agent coder --message "任务描述"

通过 CEO 调用指定员工执行任务

openclaw agent --agent writer --status

检查员工状态

🌍 网络与代理配置

git config --global http.proxy http://127.0.0.1:端口

设置 Git HTTP 代理（用于 GitHub 推送）

git config --global --unset http.proxy

取消 Git 代理配置

ssh -T git@github.com

测试 SSH 连接（端口22）

ssh -T -p 443 git@ssh.github.com

测试 SSH over 443 连接

💾 Git 基本操作

git status

查看当前状态（修改、新增、删除的文件）

git add .

添加所有变更到暂存区

git commit -m "更新描述"

提交变更

git push origin main

推送到 GitHub

git pull origin main

拉取最新变更（多设备同步时使用）

git log --oneline -5

查看最近 5 条提交记录

🔍 调试与排查

openclaw config list

查看当前配置

openclaw doctor --verbose

详细健康检查（包含日志）

Test-NetConnection github.com -Port 443

PowerShell：测试 443 端口连通性

curl -I https://github.com

测试 HTTPS 连接（需安装 curl）

ssh -vvv git@github.com

SSH 调试日志（查看详细连接过程）
