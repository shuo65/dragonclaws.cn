📦 1. 环境准备

在安装 OpenClaw-CN 之前，需要确保系统满足以下要求：

  • 操作系统： Windows 10/11（推荐），macOS，Linux
  • Node.js： v18 或更高版本
  • 内存： 至少 8GB RAM（推荐 16GB）
  • 网络： 需要访问 GitHub 和模型API

💻 2. 安装OpenClaw-CN（汉化版）

npm install -g @openclaw/zh

或使用一键安装脚本：

curl -sL https://get.openclaw.cn/zh | bash

⚙️ 3. 初始化配置向导

运行初始化命令，按照提示完成配置：

openclaw init

🐛 4. 解决中文用户名导致的编码问题

常见问题： Windows 用户名含中文导致网关闪退

解决方案：修改 OpenClaw 数据目录到无中文路径

set OPENCLAW_DATA=D:\openclaw-data

🤖 5. 免费模型配置（硅基流动）

推荐使用硅基流动（SiliconFlow）的免费模型：

  1. 访问 硅基流动官网
  2. 注册账号并获取 API Key
  3. 在配置文件中添加模型

⌨️ 常用命令速查

命令说明
openclaw gateway start启动网关
openclaw gateway stop停止网关
openclaw status查看状态
openclaw models list列出模型
