针对 OpenClaw 使用过程中的常见问题，提供经过验证的解决方案

🦞 网关中文路径乱码闪退

严重 Windows v2026.4.2+

问题：Windows 用户名含中文（如"用户名"）导致网关闪退、openclaw gateway restart 超时、计划任务失败。

原因：OpenClaw 使用 %USERPROFILE% 作为默认配置目录，中文路径导致编码问题。

解决方案：

  1. 将 OpenClaw 安装到纯英文路径（如 D:\OpenClaw）
  2. 修改 gateway.cmd，在启动前设置环境变量： 
    set "OPENCLAW_HOME=D:\OpenClaw"
cd /d D:\OpenClaw
openclaw gateway ...
  3. 同步更新所有快捷方式、计划任务、服务配置

📶 网络连接失败

常见 网络

问题：openclaw gateway start 提示连接失败、API 超时。

排查步骤：

  1. 检查网络连通性：openclaw network test
  2. 配置代理（如果需要）：openclaw config set proxy http://proxy:port
  3. 切换 npm 镜像源：openclaw config set registry https://registry.npmmirror.com

💾 内存占用过高

性能 资源管理

问题：网关内存占用过高（如 623MB）导致系统卡顿。

原因：agents.defaults.model.fallbacks 配置了过多模型，导致预加载开销过大。

解决方案：精简 fallbacks 列表，仅保留必需模型（如 1-2 个免费模型）。
