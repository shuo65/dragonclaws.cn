OpenClaw-zh v2026.3.13

发布日期: 2026-03-13 | 维护者: 龙爪中国团队

下载最新
✨ 核心特性
  • ✅ 完整中文界面本地化
  • ✅ 国内镜像源加速
  • ✅ 微信/钉钉/飞书等国内IM支持
  • ✅ 增强的文件管理器（支持百度网盘）
  • ✅ 优化国内模型API接入（百度文心、阿里通义、智谷等）
⚙️ 系统要求
最低配置:
- OS: Windows 10+  / Linux / macOS
- Node.js: 22 LTS (推荐 24+)
- 内存: 4GB (8GB+ 推荐)
- 磁盘: 1GB 可用空间

推荐配置:
- Node.js: 24+
- 内存: 16GB+
- GPU: NVIDIA (可选，用于本地模型)
- 网络: 稳定的互联网连接（用于API调用）
📦 安装方式
# 1. 安装汉化版
npm install -g openclaw-zh

# 2. 初始化配置
openclaw-zh onboard

# 3. 启动服务
openclaw-zh start

🎯 适用场景

🟢 适合中文版 (zh) 的情况
  • 用户主要在国内，需要中文界面
  • 集成微信、钉钉、飞书等国内IM
  • 使用百度文心、通义千问等国内模型
  • 希望快速上手，有中文文档
🔵 适合社区版 (cn) 的情况
  • 追求开源自由，愿意参与社区
  • 需要最新功能和快速迭代
  • 使用国际主流模型和平台
  • 有技术能力自行定制和扩展
🟣 适合企业版的情况
  • 大型企业，需要专业支持
  • 强安全合规与私有化部署
  • 定制行业解决方案
  • 需要SLA保障
